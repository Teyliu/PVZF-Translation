<align=center><size=130%>식물 vs 좀비: 퓨전 - 3.8.1 업데이트 변경점</size></align>

1. 신들의 전쟁: 진화 - 리워크+
- 더 많은 진화 루트와 업그레이드 버프 추가
- 신들의 전문가 식물들이 추가되었습니다

2. 젠가든 업그레이드
- 빠른 이동을 위한 페이지 스킵 기능이 추가되었습니다
- 배경 변경 기능이 추가되어, 이제 정원의 분위기와 조명을 조절할 수 있습니다
- 연불꽃 코인이 추가되었습니다. 다 자라고 호감도가 최대치인 식물을 판매하면 연불꽃 코인을 획득하며, 이를 통해 새로운 도구 상점에서 대량의 도구를 구매할 수 있습니다
- 젠가든과 그랜드 가든이 이제 완전히 분리되어, 더 이상 두 가든 간에 식물을 이동할 수 없습니다

3. 새로운 식물
  - 얼음 선인장 (얼음 버섯 + 선인장)
  - 체리 가스 버섯 (체리 폭탄 + 가스 버섯)
  - 바다 횃불 (횃불나무 + 바다 버섯)
  - 뜨거운 바다 버섯
  - 멜론 박격포 (삼발슈터 + 멜론 펄트)
  - 옥수수 박격포 (삼발슈터 + 옥수수 펄트)
  - 삼콩호박 (삼발슈터 + 호박)
  - 얼음박 (얼음 버섯 + 호박)
  - 화분로버 (블로버 + 화분)
  - 가스파이크 (가스 버섯 + 스파이크위드)
  - 양배추 박격포 (삼발슈터 + 양배추 펄트)
  - 파멸 삼발슈터 (파멸 버섯 + 삼발슈터)
  - 스타시 (스쿼시 + 스타푸르츠)
  - 삼콩화분 (삼발슈터 + 화분)
- 고급 식물:
  - 백설마녀 콩 (위칠리 콩 + 백설콩)

- 오디세이 식물:
  - 하위종:
    - 타이푼 킹 블로버 (블로버 + 더블로버)
    - 각성 백설마녀 콩 (업그레이드된 백설마녀 콩, 도감 확인바람)
    - 엔더 호박스 (호박스 + 크로노 호두)
- 승급종:
    - 진 피닉스 삼발슈터 (할라페뇨 + 삼발슈터)
    - 진 피닉스 드론 (진 피닉스 삼발슈터 + 블로버)
  - 상위종:
    - 열탕 버섯 (작열 캣테일 + 바다 버섯)
    - 흑요석 호두 요새 (빙염 할라페뇨 + 거대 호두 요새)
  - 유색 패킷 식물:
    - 특전사 지뢰슈터 (특전사 콩 + 감자 지뢰)
    - 저격 별콩 (저격콩 + 스타푸르츠)
 - 레전더리 식물
  - 특전사 먹깨비질라
- 스텔라 식물:
  - 스텔라 망각 버섯

4. 새로운 좀비
- 일반:
  - 좀비 호두
  - 기가 좀비 호두
  - 기반암 키다리 호두 예티
- 오디세이:
  - 일반
    - 기가 미식축구 깃발 좀비
    - 기가 미식축구 호두 깃발 좀비
    - 특무장 임프
  - 연옥 보스
    - 언데드 플랜테라
  - 에불루션
    - 기가 코끼리 좀비
    - 기가 매머데드 좀비
    - 기가 매머데드 우두머리 좀비
  - 보스 좀비:
    - 복수의 스트라이커

5. 밸런스 조정
- 망각 버섯 버프 리워크: 폭발은 폭발으로 > 폭발성 차단막, 이제 대가를 치르는 대신 모든 피해에 면역이 됩니다.
- 퀀텀 옥수수 & 퀀텀 호두의 버프 및 특수 능력 리워크
- 스쿼시 지옥불나무 & 지옥별나무: 더 많은 종류의 투사체를 점화할 수 있게 되었으며, 이제 3×3 범위내에 300 피해를 주게 조정되었습니다.
- 특무장 가르강튀아 버프 리워크: 이제 내려찍기 사용시 해당 속성에 맞는 특무장 임프를 소환합니다.
- 해당 라인에서 잔디깍기를 잃으면, 잠시 동안 해당 라인에는 좀비가 생성되지 않습니다.

6. QOL 편의성 개선
- T키를 누르면 투사체 대미지 오버레이를 표시하는 새로운 기능이 추가되었습니다 (설정에서 확인 가능)
- 새로운 UI 위치 사용자 지정 설정이 추가되었습니다
- 버프 도감에서 현재 버프들을 볼 수 있는 새로운 '모든 버프 보기' 화면이 추가되었습니다
