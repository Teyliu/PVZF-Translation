<align=center><size=130%>식물 vs 좀비: 퓨전 - 3.9 업데이트 변경점</size></align>

1. 신들의 전쟁: 진화
- 연옥 모드 추가
- 새로운 시련 버프가 추가되었습니다. 처음에는 디버프로 시작하지만, 시련을 완료하면 버프로 변경됩니다.
- 권장 레벨에서의 접근

2. 새로운 식물
  - 차원 호박
  - 코인 버섯 (뻐끔 버섯 + 금잔화)
  - 떡상 버섯 (가스 버섯 + 금잔화)
  - 은 최면 버섯 (최면 버섯 + 금잔화)
  - 황금 최면 버섯
  - 꼬마 체리 폭탄 (체리 폭탄 + 뻐끔 버섯)
  - 덥석이 버섯 (먹깨비 + 겁쟁이 버섯)
  - 큰우산 버섯 (가스 버섯 + 우산잎)
  - 파멸 화분 (파멸 버섯 + 화분)
  - 파멸 우산잎 (파멸 버섯 + 우산잎)
  - 바다 먹깨비 (먹깨비 + 바다 버섯)
  - 콜드 스타푸르츠 (얼음 버섯 + 스타푸르츠)
  - 한입 버섯 (먹깨비 + 가스 버섯)
  - 야금 버섯 (먹깨비 + 뻐끔 버섯)
  - 바다 화분 (바다 버섯 + 화분)
  - 갈릭스타 (스타푸르츠 + 마늘)

- 오디세이 식물:
  - 하위종:
    - 서리가시 식난로 (새벽 식난로 + 눈가시 알로에)
  - 상위종:
    - 미믹 크라켄 (억만 크라켄 + 좀비 상자)
  - 유색 패킷 식물:
    - 특전사 콩깍지 버섯 (특전사 콩 + 가스 버섯)
    - 겁쟁이 저격콩 버섯 (저격콩 + 겁쟁이 버섯)

3. 새로운 좀비
- 일반:
  - 미식추국 장대 좀비
  - 캣 스쿼시 좀비
  - 보스 좀비:
    - 라스트 스트라이커 (구현 완료)
    - 잭슨 유니버스

4. 버프
- 좀비 버프 6종 추가

4. 새로운 스킨 추가
- 흑요석 키다리 호두 - 흑요석 빙벽 기사

6. 밸런스 조정
- 설원 매커니즘 리워크: 기본 바닐라 식물들은 이제 설원 맵에서 75 태양이 더 소모됩니다. 자세한 내용은 메커니즘 도감에서 확인하세요. 또한 식난로, 혹한 눈덩이 대포병, 혹한 삼지창 투창병의 업데이트된 도감 항목도 확인해 보세요.
- 파멸 블로버:잿불 상태 좀비 대상 대미지 200% 효과 제거
- 파멸 선인장: 투사체 2회 관통 및 잿불 디버프 부여
- 파멸 버섯은 이제 수중 타일에서 폭발 시 해당 타일에 파멸 수련잎 생성 (자세한 내용은 수련잎 도감 참고)
- 크로노 파멸 버섯 & 네뷸라 버섯: 시간 분열 지속 시간을 하향 조정했으나, 이미 시간 분열 상태인 좀비에게 적용되는 시간 분열 효과(경과 시간 증가 방식)를 대폭 강화했습니다.
- 오디세이 승급종 식물: 이제 상응하는 해당 버프 2개를 획득한 후 전용 해금 버프를 얻어야 해금할 수 있습니다.
- 오디세이 상위종 식물은 오디세이 저주 모드에서 가격이 인상되었습니다.
- 하극상 버프: 이제 오디세이 저주 모드 상점 전용 버프로 변경되며, 좀비 버프로 등장하지 않습니다.

7. QOL 편의성 개선
- 대미지 표시 기능 추가 (설정에서 켜고 끌 수 있음)
- 화면 흔들림 효과(할라페뇨 및 파멸 버섯)를 비활성화하는 설정 옵션 추가
- 더욱 세밀하게 조정 가능한 게임 속도 설정 추가
- 젠가든 도구 상점에 즉시 성장 비료 추가, 사용 시 식물이 즉시 최고 단계로 성장
