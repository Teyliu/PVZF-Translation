1. 신들의 전쟁: 진화 - 리워크
- 식물 제한, 난이도 레벨, 진행 단계 등 다양한 게임플레이 커스텀 옵션이 추가되었습니다.
- 이제 버프들은 여러 티어로 나뉘며, 새로운 식물을 획득하거나 기존 식물을 업그레이드하는 데 사용할 수 있습니다.
- 신들이 선사하는 특별한 효과들을 눈여겨보세요. 게임을 뒤흔들 정도로 강력할 수 있습니다!
  * (참고: 메인 메뉴의 새로운 "추천 레벨" 버튼을 통해 이 레벨에 입장할 수 있습니다. 한국어판에선 일부 전용 버프 선택 후 글자 깨짐 현상 있음)

2. 새로운 식물
- 기본 식물:
  - 겨울 폭탄초
- 기본 퓨전:
  - 눈가시 죽순 (겨울 죽순 + 눈가시풀)
  - 눈가시 연꽃 (눈연꽃 + 눈가시풀)
  - 콩 화분 (콩슈터 + 화분)
  - 눈가시 가문비 (가문비 가시슈터 + 눈가시풀)
  - 파멸 멜론 (파멸 버섯 + 멜론 펄트)
  - 눈가시 알로에 (아쿠아 알로에 + 눈가시풀)
  - 호박스 (호박 + 호박 (풀 체력))
  - 파멸 옥수수 펄트 (파멸 버섯 + 옥수수 펄트)
  - 별콩슈터 (콩슈터 + 스타푸르츠)
  - 불호박 (할라페뇨 + 호박)
  - 파멸 켈프 (파멸 버섯 + 엉킨 켈프)
  - 프리클위드 (스파이크위드 + 선인장)
  - 꽁꽁꽃니 (꽃니바퀴 + 눈가시풀)
  - 케일위드 (스파이크위드 + 양배추 펄트)
  - 스프링위드 (스파이크위드 + 멜론 펄트)
  - 솔라위드 (해바라기 + 스파이크위드)
  - 더블로버 (블로버 + 블로버)
  - 횃불 지뢰 (감자 지뢰 + 횃불나무)
  - 뜨거운 감자 (횃불 지뢰로만 생성 가능)
  - 겁쟁이 콩 버섯 (콩슈터 + 겁쟁이 버섯)
  - 감자 드론 (감자 지뢰 + 블로버)
- 오디세이 퓨전:
  - 일반:
    - 빙하 버섯 (얼음 파멸 버섯 + 얼음 버섯)
    - 큐어 챠밍 캣테일 (최면 버섯 + 캣테일 걸)
      * (참고: 삽을 파내서 육상폼으로 변경 가능해요)
    - 흑빙하 버섯 (빙하 버섯 + 파멸 버섯)
  - 상위종:
    - 마그마 버섯 (양동이슈터 + 미식축구 개틀링)
  - 유니크:
    - 저격콩 화분 (저격 콩 + 화분)
    - 특전사 콩호박 (특전사 콩 + 호박)
    - 특전사 땅콩 (특전사 콩 + 호두)
    - 먹깨비 저격콩 (저격 콩 + 먹깨비)
 - 미스테리 모드 식물:
  - 기반함 키다리 호두
- 기타/특수:
  - 웅동자

4. 오디세이 업데이트
- 기가 해골군마 사령관 루트 추가
- 기존 루트에 맞춰 출현하는 좀비 조정
- 일반 오디세이에서 신들의 전쟁: 진화로부터 다이아 버프를 획득할 수 있는 가능성이 추가되었습니다.
- 네이팜 버섯 + 파멸자 버섯의 시너지 버프 "불과 얼음의 힘" 추가
- 추가된 아군:
  - 꼬마 해골마 대장 (기가 해골군마 사령관)
  - 임프 황금알보트 (임프 제왕선)
  - 피쉬트론 Jr. (하늘의 파수꾼)

5. 새로운 레벨
- 미니게임:
  - 오디세이 가챠: 가챠 상자
  - 손수레 챌린지
  * (참고: 클리어시 손수레 도구 해금됨)
  - 타임 어택

6. 밸런스 조정
- 토치위드는 이제 땅콩 투사체를 점화할수 있습니다.
- 치킨 좀키와 메카 치킨 좀키의 속도를 줄였습니다.
- 테솔라 자석 여왕이 생성하는 금속 물체의 양을 줄이는 동시에 잠재적인 대미지 증가 효과를 높였습니다.
- "저주" 메커니즘(기가 해골군마 사령관 및 녹슨 사다리 좀비가 보유)이 전면 리워크되었습니다.
- 황금 특무장 가르강튀아는 이제 거대해진 직후에만 전체 화면 공격을 단 한 번만 수행합니다.

7. QOL 편의성 개선
- 게임이 최신 버전이 아닐 경우, 메인 메뉴에 업데이트 옵션이 표시됩니다. (인터넷 연결 필요)
<color=red>* (경고: 이 기능은 Blooms 번역 모드와의 호환성 및 정상 작동 여부가 테스트되거나 검증되지 않았습니다.)</color>
- 버프 도감 추가
- 식물 체력 표시 방식이 리워크되었습니다.
- 서바이벌 저장 시스템이 리워크되어 더 많은 저장 슬롯과 커스텀 이름 지정을 지원합니다.
- 레벨을 시작하기 전, 등장하는 모든 좀비 라인업을 미리 볼 수 있는 기능이 추가되었습니다.
- 좀비가 식물을 공격해야 하는 상태라면, 공격과 공격 사이에 앞으로 이동할 수 없도록 수정되었습니다.
- 슈퍼 레벨 에디터의 노드 에디터에 변수 시스템이 추가되었습니다.
- "축복이자 저주" 시스템이 적용된 미니게임에 난이도 선택 메뉴가 추가되었습니다.
- 타워 디펜스가 챌린지 메뉴로 이동했습니다.
