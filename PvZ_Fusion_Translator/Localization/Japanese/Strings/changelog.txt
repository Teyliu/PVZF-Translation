①旅行モードリニューアル
 ※ミニボスルート、難易度、ステージ進行の組み合わせを自由に選択できるようになり、より柔軟なプレイが可能になりました。
 ※既にすべての修正効果を確認していない限り、再抽選時に同じ修正効果が重複して表示されることはなくなりました。
 ※最初の修正効果ショップとミニボス選択のタイミングが変更されました。最初の修正効果ショップはラウンド5以降に表示されるようになりました。煉獄以上の難易度では、以前の4体ではなく6体のミニボスを選択する必要があります。
 ※究極フットボールストライカーとマイケルのスーパーライブ移動車に、ゾンビ波の構成と専用のゾンビ修正効果が異なる新しいミニボスルートが追加されました。
 ※黒曜石装甲ガーガンチュアとインプの王・鴨の箱舟は、ミニボスルート以外でも選択可能なミニボスになりました。
 ※右下の「プリセット」ボタンで、バージョン3.5以前の旅行レベルにアクセスできます。

Rewinding can be only be used a limited number of times.

 ※ガーデンディフェンス entrance moved to 禅ガーデン

⑥新しいシナジー
 ※When 腐朽サラダパルト and ＳＰつららガトリングキノコ are planted on the same tile, the latter's 弾丸s split one additional time. Both plants' normal and special 弾丸s inherit some properties from each other's shots.（WARNING: Will cause lag）

⑦新しいスパーレベルエディター設定
 ※スパーレベルエディター now allows creation, modification, and linking of nodes to define レベルイベント through a pseudo-code system.
 ※You can now create リズムゲーム-style levels and ＴＤレベルs using 道標の矢印s.
